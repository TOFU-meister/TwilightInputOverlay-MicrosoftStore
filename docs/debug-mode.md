# Microsoft Store版の診断モード

ゲームを終了し、BepInExの起動ログにある `Settings:` のフォルダーから `settings.ini` を別名でバックアップします。詳細を調べるときは、元のINIに次のセクションを追加または更新し、ゲームを起動します。

```ini
[Debug]
EnableDebugMode=true
```

既定値は `false` です。項目がない場合や `true`／`false` として読めない場合もOFFです。設定はゲーム起動時に読み込みます。有効化・無効化には再起動が必要です。通常の設定保存とプリセット切り替えは指定値を維持します。同じRelease DLLで使えます。

| 対象 | OFF時 |
| --- | --- |
| 設定トップのDebug欄（単独設定・HSRTimer内共通） | 見出し、詳細ログ操作、パフォーマンス計測の開始・停止、CSV出力、状態表示をまとめて非表示 |
| 診断カウンター | 通常キーのマスク、Mouse Overlayの形状、Raining Keysの生成・破棄・再生成・再利用や描画回数などの累計を更新しない |
| 診断計測・ログ | 計測が開始されないため、周期サンプリング、描画計時、診断CSV生成を行わない。Mouse OverlayとRaining Keysの任意の詳細ログも停止 |
| 通常機能 | キャッシュの実エントリ数・ピクセル予算・退避順序、描画・入力、復旧の待機、再生成と解放、通常の警告・エラーは維持 |

ONで起動した後、Debug欄の既存の詳細ログスイッチ（INIの `debug_info`）とパフォーマンス計測が使えます。これらは個別の操作で開始します。

## Windows実機での確認

1. devのx64 Release DLLをビルドして入れ替えます。診断モードをOFFにして起動し、単独設定と、HSRTimer内のInput OverlayタブでDebug欄が表示されないことを確認します。
2. 通常キー、Mouse Overlay、Raining Keysを有効にします。角丸あり・なし、左右分割キー、長押し・解放を確認します。設定の保存とプリセット切り替えも確認します。
3. ゲーム終了後に `EnableDebugMode=true` とし、再起動します。詳細ログ操作と計測開始・停止を確認し、5秒以上計測して `overlay-performance.csv` を出力します。設定保存・プリセット切り替え後はフラグがONのままであることも確認します。
4. ゲーム終了後に `false` に戻して再起動し、通常表示に戻ることを確認します。設定全体を戻す場合はゲームを終了してから試験前のINIを戻します。
