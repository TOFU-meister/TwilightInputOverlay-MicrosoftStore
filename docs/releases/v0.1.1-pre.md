# TwilightInputOverlay Microsoft Store v0.1.1-pre

Human: Fall Flat Microsoft Store／Xbox PC 版向けの非公式プラグインです。

## 対応環境と導入

Windows x64、Unity 2019.4.24f1、BepInEx 6.0.0-be.793 Unity IL2CPP Windows x64 に対応します。ゲームを終了し、Assets の **`TwilightInputOverlay-v0.1.1-pre.dll`** をダウンロードして `BepInEx\plugins` の直下へ置いてください。旧版 DLL は外してください。GitHub の **Source code (zip)** は導入には使いません。

**HSRTimer Microsoft Store `0.1.2-pre`** と併用できます。両方導入したら Home で HSRTimer の設定画面を開き、**Input Overlay** タブを選びます。詳しい手順は [README](https://github.com/TOFU-meister/TwilightInputOverlay-MicrosoftStore/blob/v0.1.1-pre/README.md) を参照してください。

## 変更点

- Raining Keys のテクスチャキャッシュ管理と破棄処理を修正しました。無効なテクスチャの参照を避け、`Texture.get_width` の `NullReferenceException` と `Queue empty` の連続を防ぎます。角丸の描画に失敗した場合は矩形で表示します。

## 確認結果と既知の制限

Windows 実機では両プラグインの読み込み、HSRTimer の設定画面と Input Overlay タブ、Raining Keys の連続例外解消、Train の IL PB 更新が確認されています。最新ログにエラーや実行時例外の出力はなく、起動時の Il2CppInterop 警告は残っています。PB バックアップの ON/OFF によるファイル生成の違いは自動テストで確認済みです。

この配布は Microsoft Store／Xbox PC 版向けです。BepInEx は別途導入してください。
