# TwilightInputOverlay Microsoft Store v0.1.2-pre

公開用リリースノート案。添付予定は `TwilightInputOverlay-v0.1.2-pre.dll` です。

## 日本語

Human: Fall Flat の Microsoft Store／Xbox PC版向け入力表示プラグインです。Windows x64、BepInEx **6.0.0-be.793 Unity IL2CPP Windows x64** が必要です。

### 変更点

- 通常キー、マウス表示、Raining Keysのテクスチャ管理を改善しました。通常キーは押下色が変わっても同じ角丸を再利用します。Raining Keysは角丸バーを1枚のマスクで描く方式を維持し、描画に失敗した場合は矩形で表示を続けます。
- キー・マウス・Raining Keysの小数設定は確定・保存時に小数点以下2桁にそろいます。
- 診断用の操作は通常の設定画面から非表示になりました。[開発者向けの診断手順](../debug-mode.md)

### 導入・更新

1. ゲームを終了します。初めて使う場合は [導入ガイド](../../README.md#インストール方法) に沿って BepInEx を入れます。
2. `TwilightInputOverlay-v0.1.2-pre.dll` を `BepInEx\plugins` の直下に置きます。更新の場合は、サブフォルダーにあるものも含め、先に旧Overlay DLLを外します。設定フォルダーやプリセットはそのまま使えます。
3. ゲームを起動し、**Home**（初期設定）で設定を開きます。対応するHSRTimerを併用し、タブ登録が成功した場合は、HSRTimerの設定キーで開いて **Input Overlay** を選びます。単独利用時や旧ホストでは独立した設定画面を使います。

Windows実機ではHSRTimer `0.1.3-pre` との統合、通常キー・マウス・Raining Keysの表示、起動ログ3件でError 0件を確認しました。従来のIl2CppInterop起動時警告は残ります。

## English

An input display plugin for the Microsoft Store / Xbox PC version of Human: Fall Flat. Requires Windows x64 and **BepInEx 6.0.0-be.793 Unity IL2CPP Windows x64**.

### What changed

- Improved texture handling for regular keys, Mouse Overlay and Raining Keys. Regular keys reuse rounded shapes when their colors change. Raining Keys still draws each rounded bar with one mask and falls back to a rectangle if rounded drawing fails.
- Decimal settings for keys, mouse and Raining Keys are rounded to two decimal places when confirmed and saved.
- The normal settings screen hides troubleshooting controls by default. [Developer diagnostics guide](../debug-mode.md)

### Install or update

1. Close the game. For a first installation, follow the [BepInEx setup guide](../../README.md#インストール方法).
2. Place `TwilightInputOverlay-v0.1.2-pre.dll` directly in `BepInEx\plugins`. When updating, remove the old Overlay DLL first, including any copy in a subfolder. Keep your existing settings and presets.
3. Start the game and press **Home** (the default settings key). If a compatible HSRTimer registers the tab, use HSRTimer's settings key and select **Input Overlay**. On its own, or with an older host, Overlay opens its standalone settings window.

Windows testing confirmed integration with HSRTimer `0.1.3-pre`, regular keys, Mouse Overlay and Raining Keys, and zero errors across three startup logs. The existing Il2CppInterop startup warnings remain.
